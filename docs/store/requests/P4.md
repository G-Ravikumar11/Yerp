# P4 requests to the lead

No frozen file was edited. One workaround that a shared change would make unnecessary:

## Stores a transfer can go to (`routers/store_lookup.py`, `features/store/shared/StorePicker.tsx`)

`GET /api/store/lookup/stores` lists the stores **this person may work in** (their assignments, or all for the account holder and `store.admin`).
A transfer's destination can be any store of the company - only *receiving* needs access to it - so a store keeper assigned to one store could not
pick another as the destination with the shared picker.

P4 worked around it with its own `GET /api/store/control/pick/stores` (every active store of the company) and a small destination `<Select>` in
`features/store/control/Forms.tsx`.

Wanted, if you prefer one picker: `GET /api/store/lookup/stores?scope=all` returning every active store of the company, and a `scope="all"` prop on
`StorePicker` that passes it through. P4 would then drop its own endpoint and select.
